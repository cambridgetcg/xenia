# Third-party boundary

The files in this provider directory are a private source-derived consumer fixture from AgentTool Telescope. They are Apache-2.0 software, not newly authored MPL-2.0 XENIA implementation. Original license and NOTICE texts are preserved under imported/agenttool/packages/telescope/. The facade is Apache-2.0 as marked. See provenance.json for exact source and generated-file identities.

This is not an npm/LOVE release, the published Telescope 0.2.3 artifact, or its MCP bundle. The local private package version is deliberately distinct. No host installation, service, model or credential is required. Only the parser is exposed by index.mjs; transport definitions in its unmodified dependency closure are not invoked by the XENIA adapter.
